📖 Hướng dẫn sử dụng chi tiết
Cấu hình thanh công cụ (Bên trái):
API Key Gemini: Dán mã API nếu muốn dùng trí tuệ nhân tạo (hoặc để trống để chạy Offline).
Xưng hô: Bật/tắt xưng hô Thầy/Cô.
Phong cách lời phê: Chọn Ngắn gọn, Gần gũi, Khích lệ hoặc Đầy đủ.
Loại đánh giá: Chọn Môn học hoặc PC-NL hoặc HĐGD.
Thời điểm & Môn học: Chọn đúng Kỳ học và Khối lớp.
Tải lên danh sách học sinh:
Kéo thả file Excel bảng điểm của lớp vào khung tải dữ liệu.
Thực hiện nhận xét:
Bấm nút "🚀 Thực hiện nhận xét Tự động".
Copy và Dán kết quả vào Excel:
Nhấn chuột vào khung kết quả, ấn Ctrl + A rồi Ctrl + C.
LƯU Ý KHI DÁN: Chỉ click chuột 1 lần vào ô đầu tiên của cột nhận xét trên Excel (để hiện viền xanh, không nháy đúp), rồi ấn Ctrl + V.
